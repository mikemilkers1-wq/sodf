# County Governance — RCSO 0.43

Adds a shared County Governance section backed by `county_governance_state`.

- County Administration: Governor William Bracken, election, NFFA, cabinet and 20-member Senate.
- County Agencies: 13 agency profiles.
- RCSO and RDOT logos included where available.
- Other agency logos intentionally remain placeholders.
- Only unlocked RinCEN Finance Director / Assistant Director sessions can edit agency entries.
- All terminals read the same Neon record.

No manual SQL is required.
